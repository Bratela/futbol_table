# Турнирная таблица (футбол / футзал)

Универсальная одностраничная программа для ведения турнира: группы, расписание, таблицы, плей-офф, итоговые места и форма для печати. Один файл `index.html` (HTML + CSS + JavaScript), без библиотек и сервера. Работает в телефоне и на компьютере.


Интерфейс на двух языках: **русский** и **латышский** (кнопки RU / LV). Есть тёмная и светлая тема (кнопка ☀️ / 🌙).

## Возможности

- **Группы и команды.** Любое число групп и команд; названия можно менять.
- **Расписание строится автоматически.** В группах каждый играет с каждым; время матчей считается от времени начала и длительности одного матча.
- **Таблицы групп** пересчитываются при вводе счёта: игры, победы, ничьи, поражения, мячи, разница мячей, очки.
- **Плей-офф** (три режима):
  - *Крест-накрест* — для двух групп: 1A–2B и 1B–2A, игры за остальные места (3–4, 5–6 и т. д.), финал.
  - *Олимпийская сетка* — для любого числа групп; вы задаёте, сколько команд из группы выходит дальше, и можно включить матч за 3 место.
  - *Без плей-офф* — только групповой этап.
- **Пары плей-офф подставляются сами**, когда в группах сыграны все матчи. При ничьей в плей-офф выбирается победитель по пенальти.
- **Итоговые места** заполняются по мере игры.
- **Форма печати** (формат A4) в стиле бумажного листа: группы, расписание, колонка счёта, итоговые места. Можно распечатать пустой бланк для записи от руки или форму с результатами.
- **Сохранение** данных в браузере (localStorage).

## Как пользоваться

1. Нажмите **⚙ Настройки** и заполните название, дату, место, формат игр.
2. Задайте время начала и минуты на один матч.
3. Создайте группы и добавьте команды (поле «Новая команда» и кнопка «＋» или Enter).
4. Выберите вариант плей-офф.
5. Вводите счёт в блоке «Расписание и результаты» — всё остальное пересчитается.
6. Для печати нажмите **🖨 Форма печати**, при желании включите «С результатами», затем «Печать».

Кнопки в настройках:

| Кнопка | Действие |
|---|---|
| Очистить результаты | Стирает все счета, оставляет команды и группы |
| Загрузить пример | Загружает пример — турнир Jūrnieks Ziemas Kauss 2026 |
| Новый пустой турнир | Создаёт пустой турнир с группами A и B |

Опасные действия (удаление группы, очистка, замена примером) требуют повторного нажатия: первое нажатие меняет подпись кнопки, второе подтверждает.

## Правила подсчёта

- Победа — 3 очка, ничья — 1, поражение — 0.
- Места в группе: очки → разница мячей → забитые мячи → название по алфавиту.
- В олимпийской сетке участники ранжируются по месту в группе, затем по очкам, разнице мячей и забитым. Сетка строится по принципу «сильный со слабым» (1-й с последним и т. д.); число участников — наибольшая степень двойки, не превышающая число прошедших дальше.
- Команды с одинаковыми показателями не разрешаются личными встречами — для спорных случаев смотрите регламент своего турнира.

## Печать

В форме печати есть переключатель **«С результатами»**:

- выключен — пустой бланк: команды и расписание есть, колонка счёта и таблицы пустые;
- включён — форма с текущими результатами и итоговыми местами.

Если кнопка «Печать» не срабатывает во встроенном просмотре приложения, откройте страницу в обычном браузере и нажмите Ctrl+P (на телефоне — «Поделиться → Печать»). Будет напечатана именно форма печати.

## Ограничения

- Данные хранятся только в браузере на этом устройстве: они не переносятся на другие устройства и могут пропасть при очистке данных сайта.
- Расписание строится автоматически и не редактируется вручную: порядок матчей зависит от порядка команд в группе.
- Тексты, введённые вами (название турнира, места, примечания, названия команд), не переводятся при смене языка.
- Не учитываются дополнительное время и серия пенальти как счёт: пенальти только определяют победителя ничьей в плей-офф.

## Устройство

Весь код в одном файле `index.html`:

- `state` — состояние турнира (информация, группы, команды, счета, язык, тема);
- `pairs()` — пары «каждый с каждым» внутри группы;
- `playoffDefs()` — матчи и итоговые места для выбранного режима плей-офф;
- `resolve()` — таблицы групп и подстановка команд в пары плей-офф;
- `renderMain()`, `renderSettings()`, `renderPrint()` — отображение;
- `I18N` — переводы на русский и латышский (чтобы добавить язык, скопируйте один из блоков и переведите строки).
